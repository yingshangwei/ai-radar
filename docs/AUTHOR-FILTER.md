# 按发言人筛选

雷达、收藏列表中的「发言人」按钮打开可搜索的选择面板，支持姓名和 @账号搜索。选择一个发言人后，只显示此账号的消息；点击右侧 × 或选择「全部发言人」清除。与主题、来源、关键词、仅重点、排序及收藏条件叠加。

- `/v1/articles?author=x:handle:openai` 按平台与规范化账号精确匹配，在分页/计数前过滤。无 handle 的文章按平台与原始作者名称匹配（如 `rss:name:研究员: 小明`）。同名不同账号、不同平台、正文提及或引用对象不混入。
- `/v1/article-authors` 与列表共用 `article_query()`。返回当前条件下全部匹配数据的作者及数量，不限于 App 已加载的第一页，也不限关注名单。展示名采用该账号最新一条匹配文章中的名字。
- 普通雷达沿用最近七天窗口、搜索及低信息量准入规则；收藏沿用已收藏历史记录的范围。筛选仅改变读取条件，不触发采集、翻译或模型调用。
- App 查询与离线缓存带独立作者参数；切换作者从第一页开始。选择面板支持空结果、失败重试和离线标记。一次选择一个账号；关闭 App 后筛选状态与其他现有列表筛选一样重置。

Android 内容版本 `0.13.0.12`，沿用 runtime `0.13.0`；不新增依赖、权限或原生模块。iOS 共用界面实现，当前仍无经过原生验证的 iOS 发布基线。
