# Math rendering

KaTeX 0.18.7 is pinned in `pnpm-lock.yaml` and distributed under its MIT license.
`scripts/build-math-assets.cjs` embeds its JavaScript, WOFF2 fonts, CSS and full license in an offline document.
The generated `src/generated/katexAssets.ts` is ignored by Git and regenerated by `pnpm install`, `pnpm typecheck`, or the repository Android build script.

KaTeX runs with `trust: false`, expansion/size limits and a restrictive content security policy. The document has no external scripts, fonts, image requests, navigation or shared cookies. Article text is HTML-escaped; unsupported TeX remains visible as source text.

Upstream: https://github.com/KaTeX/KaTeX
