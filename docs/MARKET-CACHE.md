# 手机行情缓存与增量更新

2026-09-19，内容版 0.13.0.13，沿用 Android runtime 0.13.0。

- 冷启动先读取本地快照，再联网检查版本；离线保留图表和观测时间，并明确标识缓存。前台行情页每 60 秒检查，服务器正在刷新时 15 秒后再检查。离开行情页/进入后台取消请求和定时器。
- 缓存按服务地址、令牌身份、完整筛选参数隔离。凭据身份只进入 SecureStore（Web 使用 sessionStorage），数据缓存键不含令牌。更换身份或退出登录清除行情缓存，认证失败隐藏旧数据并清理缓存。取消的旧请求不能覆盖新筛选结果或在退出后写回。
- 设备保留最多 4 个筛选视图、约 3 MB UTF-16 预算，单个条目不超过 1.5 MB；7 天后失效。存储配额不足不影响联网结果。不同时间范围、付款方式、金额、商家模式、聚合和平滑设置分别缓存。
- `/v1/market/view-update` 支持 `since` 版本。首访返回 `full`，版本相同返回 `unchanged`，历史版本可用时返回 `delta`。图表按时间标识数据点，保留完整片段边界；增量包含新增、修改、删除，旧 EMA 值改变也同步。版本失效或增量体积更大时返回完整当前视图。后台计算或网络故障不抹去已经展示的快照。
- 服务端保留热快照、默认视图预热，每 60 秒后台重建近期使用的视图，同条件请求合并计算。行情构建与 Mac 数据复制不再共用一个等待槽。最多 8 个筛选条件，每条件最多 16 个版本，总缓存预算 48 MB（至少保留一个有效视图）。休眠很久或服务重启后可能需要一次全视图校准，界面仍先显示设备缓存。
- 首包省略手机没有绘制的比较图、原始样本和桶明细；报价数值、时间和缺口不改写。旧 `/v1/market/view` 继续兼容。未改变采集、金融计算、数据库或 Mac 同步协议。

本地手机逻辑测试 79 passed、1 skipped，TypeScript 类型检查和 Android/Web 导出通过；代理 4 项、私有服务 7 项、Swift 54 项通过。后端全量 1,794 passed、18 skipped；另有一项既有迁移表白名单测试未列入后来新增的三张表；已在修改前 c754a37 的独立源码导出中复现同样失败。本次未改数据库或该测试。自动测试覆盖增量精确重建、历史平滑修正、缺口、账号/筛选隔离、断网冷启动、认证失败、取消旧请求、缓存上限/配额和退出后的迟到写入。
