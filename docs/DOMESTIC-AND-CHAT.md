# 国内行业来源与 Codex 对话

## 国内覆盖

在既有 22 个海外行业来源外增加 10 个免费来源，沿用原有采集队列、固定版本证据、引用校验与预算。新增来源默认每 30 分钟检查。

- 巨潮资讯：浪潮信息、科大讯飞、英维克、中际旭创、用友网络、海光信息、金山办公、寒武纪。证券代码和 orgId 来自巨潮官方 stockList。每公司最多两页 × 30 条近期公告，仅保留经营/定期报告相关标题，每次最多补两份 PDF。
- 阿里巴巴：公司官网中文香港联交所公告，明确的发布日期及 PDF 直链；只覆盖该公司当前官网窗口。
- 国家发改委：通知栏目中 AI、算力、数字经济、制造、电网、电价及产业成本政策，最多补两篇直接正文。政策背景不能当成企业收入增长证据。

PDF 复用现有 pypdf 隔离解析器，最多 8 MB、40 页、60,000 字符；截断、摘要和正文失败均保留标记。不递归跟踪附件及文中链接。日期精度保留，日期级信息按北京时间零点存储，不冒充精确发布时刻。

观察公司由 25 家增至 34 家。报告候选分别取得国内与海外样本并交替选择，在资料可用时保留国内可见性；仍受主体分散、证据长度与模型预算约束。新报告区分国内/海外，已有报告和引用不改写。国内仍是部分公司与政策覆盖，不包含全 A/H 市场、实时行情、估值或一致预期。工信部直连实测 403，未登记为已接通来源。

官方入口：[巨潮公告](https://www.cninfo.com.cn/new/hisAnnouncement/query)、[证券标识目录](https://www.cninfo.com.cn/new/data/szse_stock.json)、[阿里中文港股公告](https://www.alibabagroup.com/zh-HK/ir-filings-hkex)、[国家发改委通知](https://www.ndrc.gov.cn/xxgk/zcfb/tz/)。公开网页接口可能变化，读取失败会显示来源状态并按周期恢复，不保证全历史与秒级到达。

## App 对话

底部「对话」提供新建/切换会话、发送消息、模型选择、结果及原文链接。沿用设备访问令牌和服务器已有 Codex 授权。会话持久化在服务端，断开 App 不取消已提交任务；重新打开可以查看结果。页面读取最近 100 轮，会话列表读取最近 100 个。

模型来自独立路由配置：默认 Sol medium；可手动选择 Astra low（界面 light）或 Astra medium。这里用户选定档位直接执行一次，不叠加自动审核/升级。自动翻译、行业审核等原有三档策略保持。实际 Token 归入「分析对话」，沿用 K → M → B 显示。

官方 [Codex 非交互会话](https://learn.chatgpt.com/docs/non-interactive-mode) 支持指定会话 resume。复用项目已有 `codex_sessions` 传输：同模型继续原 CLI 会话；模型配置变化或累计 40 轮时创建新 CLI 会话，附带最多最近 12 轮的有界历史，App 会话仍保持。不同 App 会话不共用后台 CLI 会话，也不混入自动分析会话。

每轮执行前取得新的服务快照：采集窗口、翻译状态、任务队列、来源健康、行业报告及相关原文摘录。检索范围为最近 150 条消息与 100 份行业证据；明确询问国内时优先国内证据。它是有限快照分析，不是任意 SQL、主机运维终端或全库语义检索。答案显示快照时间；资料不足必须说明缺口。

CLI 运行使用 `read-only`、禁用 shell/web 工具、忽略用户配置和外部规则，不提供数据库路径、密钥或原始运维日志。对话不能修改文章、运行命令、重启服务或交易。模型仅能引用本轮快照已提供的证据 ID，未知 ID 拒绝发布；中文解释本身仍是模型判断，未额外调用付费审核模型。

## 队列与恢复

用户对话有独立 FIFO 执行器，不持有采集业务锁。默认全局最多 8 条待处理、排队最长 15 分钟、最近 24 小时最多 100 条；参数放在 `[chat]`。模型执行默认超时 300 秒。消息 ID 做幂等，网络重试同一消息不重复调用。

调用前保存预约与请求指纹。重启后验证并恢复已完成 CLI 回执；无可信回执的执行中任务显示「结果未知」，不自动重发。排队超时不调用模型，提示重新发送。新消息可在新 CLI 会话继续，保留原来的未知状态及历史。服务端只新增 `chat_sessions`、`chat_turns` 两张表。

接口均需 reader/admin 认证：`GET /v1/chat`、`POST /v1/chat/sessions`、`GET /v1/chat/sessions/{id}`、`POST /v1/chat/sessions/{id}/messages`。提交字段为 `id`、`question`、`profile`，profile 限 standard/confirmation/adjudication。数据范围沿用当前单人设备令牌，不宣称多用户隔离。

## 验证与发布

本地真实采集：八家 A 股公司及阿里官网均取得有效公告，九来源合计 35 条、18 份 PDF 正文或截取正文。本地发改委连接失败，腾讯云只读探针 HTTP 200，结构与明确发布日期已核验；正式云端采集结果以部署验收为准。

本地假 CLI 子进程覆盖真实 exec/resume 传输、档位切换、消息幂等、权限、预算、回执恢复及未知结果不重发。国内采集测试覆盖身份、原始日期、PDF 范围、主题过滤及凭证隔离；旧表迁移测试继续核对原有记录不变。Android 内容版目标 `0.13.0.4`，沿用原生 runtime `0.13.0`，无新增原生依赖。生产与热更新验收另行记录。
