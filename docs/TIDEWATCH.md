# TideWatch 行情集成

AI Radar 的「行情」页展示独立 TideWatch 服务计算的公开 OKX C2C 水位和 BTC/SOL/ETH 现货历史。采集、Decimal 计算、聚合、时间平滑和数据库复制都在私人 TideWatch 仓库；此公共仓库只提供鉴权代理及手机显示。

## 接口与配置

`GET /v1/market/view` 使用现有设备只读令牌，支持付款渠道、单笔金额、商家质量模式、1–168 小时时间窗口、聚合周期、EMA 与历史结束时间。页面每 30 秒刷新；服务器默认每 60 秒采样。真实断点和数据不足保持缺失，不补成零。

服务配置来自环境变量：

| 配置项 | 用途 |
| --- | --- |
| `RADAR_MARKET_SERVICE_URL` | 私有行情 API 地址，部署时使用回环地址 |
| `RADAR_MARKET_READER_TOKEN` | 代理读取行情的独立密钥 |
| `RADAR_MARKET_SYNC_TOKEN` | Mac 与服务器复制数据的独立密钥 |

`/v1/market/sync/state`、`export`、`import` 转发有界、幂等、带游标的复制协议。普通手机令牌不能访问这些端点。手机不保存同步密钥，不提供任意命令、交易或服务配置写入。

## 运行与数据

云端 `tidewatch-collector` 持续采集，`tidewatch-api` 只监听 `127.0.0.1:18479`，与 AI Radar 调度器分离。Mac TideWatch 0.4.0 默认作为镜像，每 60 秒双向增量同步；积压时分批连续追赶，失败保留进度，下次重试。电脑停止后云端继续，电脑恢复后补齐。数据同步不传播删除、凭据、运行状态或个人界面配置。

首次迁移使用一致性 SQLite 备份。服务器原始快照保留 7 天、指标/榜单/K 线保留 30 天；本地独立保留现有策略。双副本方便观察与备份，但不同保留期意味着两端总行数不必永久相等。

Android 内容版本 0.13.0.5，兼容现有 0.13.0 原生运行时，无新增原生依赖。iOS 共用页面源码，发布仍需要现有 iOS 签名和分发流程。
