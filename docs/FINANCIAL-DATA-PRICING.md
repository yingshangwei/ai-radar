# 金融与行业信号：付费渠道优势和费用

核验日期：**2026-09-13（北京时间）**。用途：AI Radar 的 AI 跨行业研究、经营验证和个人股票研究。本文是采购参考，**没有购买、开通账号、增加付费采集或变更现有 X 预算**。首期新增来源按免费范围实施。

建议先让免费原始披露、政策与行业数据持续运行，再用漏报记录决定买什么：中文财经覆盖不足时优先评估 Tushare；财务比较和预期差不足时评估 FMP 或 Finnhub 的具体数据包；美股突发事件漏报明显时再评估 Benzinga。LSEG、Bloomberg、Wind 留到覆盖和服务要求明确后询价。以下优先顺序是针对本项目的判断，并非供应商质量排名。

## 四、为 AI Radar 安排采购顺序

1. **当前阶段：新增数据服务预算为零。** 复用已有来源和程序，先积累公司原始披露、政策与行业证据。既有付费 X/模型费用按原配置管理，不能纳入“免费新增来源”的概念。
2. **若主要问题是中文快讯缺口：** 评估 Tushare 新闻 ¥1,000/年；若缺 A 股原始公告，再单独评估公告 ¥1,000/年。两者合计 ¥2,000/年是价格表相加，不代表必须一起购买。
3. **若主要问题是财务口径和预期：** 先用免费样本验收 FMP 与 Finnhub。FMP Premium 当前年付 $708/年可作为候选；明确需要电话会全文时，再比较 FMP Ultimate $1,788/年和其他专项报价。Finnhub Estimate-1 单市场季付 $225，适合先验证所需预测字段和覆盖。
4. **若主要问题是美股突发漏报：** 对 Benzinga 申请具体产品试用/报价前，先准备漏报事件集。已有 Alpaca 新闻若能获免费权限，可先验证；不把两个同源渠道叠加采购视作覆盖翻倍。
5. **全球专业或机构需求成熟后：** 对 LSEG、Bloomberg、Wind 用相同范围询价。NewsAPI 对广泛新闻搜索有用，但对当前股票研究，结构化预期或专业事件通常更接近待补缺口。

“适合采购”的验收指标应是关键事件漏报减少、独立证据增加、行业判断更可验证以及人工研究时间下降。新闻条数、供应商情绪分和文章摘要流畅度，不作为单独购买理由。

## 五、核验方法与仍未解决的问题

- 公开费用来自供应商当前官方价格/产品页；Finnhub 页面通过浏览器实际渲染读取，避免搜索摘要沿用旧价格。FMP 的年付价经页面确认；月付切换未返回可信新数值，故未填猜测价格。
- “需询价”表示本轮查看的官方产品页没有可用于本项目的公开数额，**不等于已拿到报价或确认供应商绝无公开促销**。没有联系销售或提交用户资料。
- 未测试付费 feed 的端到端延迟、准确率、完整性、许可下的外部模型处理、退款或当前账号权限。采购前这些仍需验收；公开页“实时”不是本系统的延迟承诺。
- 财报预测产品的历史长度不等于 point-in-time 快照能力。股票研究需要保留当时预期与之后修订，不能把今天的历史查询当成过去已经知道的结果。
- 本文只涉及数据和研究服务。数据源收费与模型、服务器、网络、维护成本分别记账；本文没有连接券商交易账户或执行投资交易。
