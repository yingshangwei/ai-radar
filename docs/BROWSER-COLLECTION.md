# 已授权浏览器采集

用户授权的脚本或 Agent 可通过现有导入接口接入社交内容，无需改变摘要引擎或 App。2026-09-07 已用用户登录的 Chrome 完成一批 X 真实采集：8 条公开帖进入腾讯云，原文、精确时间、互动指标、重点名单匹配和模型日报均已验证。

这是一次有明确边界的浏览器采集验证。服务器的 X 官方 API 仍等待 Bearer Token 与付费方式选择；这批结果不代表 X 定时采集已开启，也不代表搜索覆盖了所有近期帖子。

## 采集流程

1. 使用用户已登录的浏览器，在 X 的公开搜索页组合关键词或关注账号；本次分别检查了 Top 与 Latest 排序。查看同一事件的后续更新，避免把早期开放安排当作最终状态。
2. 只读取页面实际显示的帖子。展开 Show more，保留原文及真实帖子链接；时间取对应可见 `time` 元素的 `datetime` 属性，不从“3 小时前”推算，也不将抓取日期作为发布时间。
3. 互动数取页面无障碍标签中的完整计数，保留缺失字段；不把 `3.6M` 换算成伪精确值。本次 `view_count` 是页面浏览数，不参与现有热度评分。
4. 引用帖与主帖分开标明作者和时间。本次原始视频没有自动转录，只有视频而无可读文字的预告未纳入证据；不从画面以外补造产品细节。
5. 产出 `ImportBatch` JSON，`platform="x"`、`external_id=真实帖子ID`、`source_id="x-browser"`。标题取原文中的短句，正文保留来源措辞；每批最多 200 条。
6. 用 `radar.schemas.ImportBatch.model_validate_json` 本地校验，再调用 `POST /v1/admin/import`。日期、AI 主题、热度和去重仍由服务端统一处理；日常手机令牌无权导入。
7. 通过 reader API 回读正文、时间、指标和优先关注状态，再生成统计窗口已结束的日报。检查引用 ID 和日期范围，并人工核对事件合并与未证实说法的措辞。

本次没有导出浏览器 Cookie、调用页面内部接口或向社交平台发帖、点赞、转发。使用的导入机制与账号凭据分离，具体浏览器操作取决于用户提供的授权工具；仓库未安装未经审核的 X 抓取库。

- 8 条帖子来自 OpenAI、Anthropic、Google DeepMind、Sam Altman 和 Tibo；云端总计 33 条信息。Tibo 暂按 `tibo_maker` 关注，具体身份仍可由用户确认后调整。
- 9 月 5 日日报：Codex 约 22 秒完成，4 条 X 原文合并为 2 条中文报道。OpenAI 与 Sam Altman 的开放范围更新合并；Anthropic 的形式化证明描述与已有数学证明明确区分。
- 9 月 6 日日报：Codex 约 10 秒完成，1 条 X 消息。模型明确将 Tibo 的产品说法标为尚未证实，并保留来源。
- 9 月 4 日历史日报也已补齐：11 条输入形成 6 条报道、10 个引用；同一发布事件合并使用更完整的官方正文。结果保存在 `verified-digest-2026-09-04-with-x.json`。
- 日期窗口仍为当天北京时间 08:00 结束的前 24 小时。9 月 6 日白天采到的内容不会提前加入尚未结束的 9 月 7 日窗口。
- 原始导入批次、操作来源记录和回读日报保存在本机 Git 忽略的 `dist/cloud/x-browser-20260907*.json` 和 `verified-digest-2026-09-05.json` / `verified-digest-2026-09-06.json`。

## 持续采集仍需完成

使用官方 X API 时先确认账户费用与读取权限，再配置私有 Token，并按预算限制查询规模。若用户选择浏览器路线，还需建立实际可定时运行、能识别登录失效和页面变化的授权采集环境。单次浏览器操作不等于服务器已具备该环境。

Facebook 账号仍在审核；Meta Newsroom 是独立官方新闻源，不能代替 Facebook 社交帖的读取授权。
