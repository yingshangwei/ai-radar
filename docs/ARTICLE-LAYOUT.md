# 雷达发言布局 · 0.7.0

列表采用「作者 / 发布时间 → AI 标题 → 三行正文预览」，保留纸白、墨绿和橙色重点标识。引用使用浅色内嵌卡片，显示被引作者和时间；回复单独标注对象，详情可打开原帖。点击卡片查看完整发言，中文和原文可切换。参考 [Threads](https://about.fb.com/news/2023/07/introducing-threads-new-app-text-sharing/) 的身份信息层次、[Feedly](https://feedly.com/news-reader) 的资讯阅读结构；具体排版适配本应用。

标题由服务端正常采集、阅读及日报流程生成，复用现有摘要审核和缓存；当前原文或审核配置变化会使旧结果失效。普通 CLI 每轮最多处理三条待生成标题；0.8 的后台恢复队列每批处理一条，自动续跑，读取 API 不调用模型。已有网页摘要只有与该条自身来源、标题和正文完全一致时才可复用。未生成或未通过的标题显示来源标题，不标记为 AI，也不会拿直接关联网页的标题替代发言人的观点。

X 的回复身份取官方返回的 replied_to 关系，缺少父帖作者时只保留已知原帖链接；不凭 @ 提及推断回复，不额外追踪更深对话。引用按既有采集标记分块；中英文标记无法对应的旧数据保留完整文本，避免制造归属。未取得引用正文时明确提示，并保留标记之后仍存在的文本。此变更不手工编辑任何实际文章或译文。
