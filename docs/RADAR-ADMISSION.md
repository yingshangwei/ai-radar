# 雷达信息准入

`social-information-v1` 将信息含量与摘要事实审核分开。重点关注、点赞数、已生成摘要或前瞻结果都不能让纯表情/附和自动成为雷达消息。

- X/Facebook 的纯表情、纯赞同/寒暄不展示。
- 对短回复检查它是否有独立信息：技术参数、修复/发布、能力判断、平台上线时间、有效直接链接或实际取得的引用正文。父帖 URL、被 @ 的账号名称和引用时间戳不算正文证据。
- 不一律屏蔽回复，也不使用最低热度或最低字数挡住新信息。只有短链接的帖子保留，交给现有网页解析流程。较长、无法明确判为噪声的内容仍及时呈现。
- 这是免费的确定性最低信息门槛，不是对所有长篇发言的全面语义价值评审，不因本次修复新增逐帖 LLM 调用。

采集正常保存原文及直接引用，在独立 `article_admissions` 表记录规则版本、原文与引用指纹、可见性和原因。API 启动时调用同一个 `reconcile()` 自动评估历史原文。实际来源正文/引用变化后，下一次采集会重新判定。文章、译文、模型审核历史不会被改写或删除。

普通雷达列表（包括搜索、计数、分页）过滤不可见记录。用户主动收藏的记录和文章详情仍可访问。新的摘要、翻译、网页处理、发现候选及日报输入也应用此门槛，避免噪声继续占用资源；历史已发布日报不重写。

`GET /v1/status` 的 `admission` 字段提供版本、过滤数量和原因统计。保留的 `article_count` 是原始入库数，包含被过滤的存档。手机刷新雷达即可生效，无需安装新包。

验证覆盖中文/英文反应、AI 观点、极短技术事实、命令参数/公式、链接/引用、重点账号与高互动绕过、历史记录恢复、原文与译文保留、队列排除，以及 API 分页/搜索/收藏/计数一致性。
